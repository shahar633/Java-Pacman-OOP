# Java Pac-Man Prototype

## Overview
A Pac-Man prototype developed for a university Object-Oriented Programming course. Built on top of a provided LWJGL/OpenGL skeleton, the project focuses on implementing core software engineering principles and architecture rather than a complete game lifecycle.

## Key OOP Concepts Applied
* **Architecture:** Component-based design separating core game logic from rendering.
* **Design Patterns:** Practical implementation of Factories and Callbacks.
* **Java Features:** Extensive use of Interfaces, Polymorphism, Generics, custom `Iterable`/`Comparable` types, and functional programming (Lambdas).
* **Data-Driven:** Dynamic level loading and entity generation from text-based scene files.

## Gameplay State
Playable proof-of-concept featuring grid-based movement, entity collision detection, coin collection, and dynamic ghost behavioral states (potions).

## Tech Stack
Java, LWJGL (OpenGL).
